# TT_ServerMaker (서버 메이커)

마인크래프트 서버를 버튼 몇 번으로 열고, 친구가 연 서버에는 초대 코드 하나로 들어가는
Windows 앱입니다. 자바 설치부터 서버 구성과 포트 열기, 참가자 모드팩 맞추기까지 앱이
알아서 처리합니다.

여는 쪽과 들어가는 쪽이 한 앱에 들어 있습니다. 친구들에게도 같은 프로그램을 주면 됩니다.

> 없습니다.

## 받기

[Releases](https://github.com/Yuupering/TT_ServerMaker/releases/latest)에서 설치본을 받으세요.
64비트 윈도우용입니다.

서명되지 않은 앱이라 처음 실행할 때 Windows SmartScreen 경고가 뜹니다.
`추가 정보` → `실행`을 누르면 됩니다. 받은 파일을 우클릭해 속성에서 `차단 해제`를
체크하면 경고 없이 실행됩니다.

배포본은 개인 PC가 아니라 GitHub Actions에서 만들어집니다. 어떻게 만들어지는지는
[코드 서명 정책](CODE_SIGNING_POLICY.md)에 적어뒀습니다.

## 두 가지를 합니다

앱을 켜면 `서버 만들기`와 `친구 서버 참가하기` 둘 중에 고릅니다.
서버를 여는 사람도, 그 서버에 들어가는 사람도 같은 프로그램을 쓰면 됩니다.

## 서버 만들기

1. 앱을 켜고 `서버 만들기`를 누릅니다.
2. 어떻게 만들지 고릅니다.
   - `모드팩 서버 열기` — Modrinth에 올라온 팩을 이름으로 찾아서 바로 설치
   - `내 컴퓨터에서 가져오기` — 가지고 있는 `.mrpack`, CurseForge 서버팩 zip, 서버 폴더
   - `마인크래프트 서버 열기` — 서버 종류와 마인크래프트 버전을 직접 선택
     - 플러그인 서버: Paper(권장), Spigot, CraftBukkit
     - 모드 서버: Fabric, NeoForge, Forge, Quilt
     - 순정
3. 서버 이름을 적고 이용약관에 동의한 뒤 `서버 만들기`를 누릅니다.
4. 설치가 끝나면 `서버 켜기`를 누릅니다.
5. `접속 주소` 탭에서 주소를 만들어 친구들에게 알려줍니다.

`내 컴퓨터에서 가져오기`는 모드팩 파일을 창에 끌어다 놓아도 됩니다.
`.mrpack`과 CurseForge 서버팩 zip 둘 다 받습니다. 서버 폴더는 아래 `폴더 선택`으로 고르세요.

`마인크래프트 서버 열기`로 만들 때는 서버 파일(jar)을 직접 받아서 넣는 것이 기본입니다.
받을 주소를 화면에 띄워주니 브라우저로 받아서 넣으면 되고, 넣은 파일이 공식 파일과 같은지
앱이 해시로 확인합니다. 앱이 알아서 받게 하려면 그 아래 체크를 켜면 됩니다.
기본값을 이렇게 둔 이유는 아래 백신 관련 항목에 적어뒀습니다.

### 친구들에게 보내기

`접속 주소` 탭에서 `초대 코드 만들기`를 누르면 한 줄짜리 코드가 나옵니다.
카톡으로 그 코드와 이 앱 다운로드 링크만 보내면 됩니다.

코드에는 접속 주소와 필요한 버전·로더·모드팩 정보만 들어갑니다.
비밀번호나 계정 정보는 담기지 않습니다.

### 내 클라이언트 준비

모드 서버를 열었다면 서버 주인도 자기 게임에 모드를 맞춰야 들어갈 수 있습니다.
서버 화면 위쪽 `내 클라이언트 준비`를 누르면 알아서 처리합니다. 접속 주소는 이 PC에서
쓰는 `localhost`로 잡습니다.

CurseForge 서버팩이나 직접 넣은 폴더로 만든 서버는 클라이언트 모드가 어디 있는지 알 수
없어서 로더와 프로필까지만 맞춥니다. 서버 모드와 클라이언트 모드는 구성이 달라 그대로
복사하면 게임이 죽기 때문에, 모드는 직접 넣어야 합니다.

### 접속 주소 만들기

`공유기로 열기`를 누르면 UPnP로 공유기에 포트를 열고 접속 주소를 만들어 줍니다.
외부 서비스를 거치지 않고 집 회선으로 바로 연결합니다.

공유기가 UPnP를 막아뒀거나 지원하지 않으면, 직접 설정하는 데 필요한 값(공유기 설정 주소,
이 PC의 내부 IP, 포트, 공인 IP)을 화면에 정리해서 보여줍니다. 공유기에서 포트포워딩을
추가한 뒤 `설정 마쳤습니다`를 누르면 주소를 만들어 줍니다.

인터넷이 공인 IP를 주지 않는 환경(대부분의 아파트 공용 인터넷, 모바일 라우터)이라면
포트포워딩을 해도 외부에서 들어올 수 없습니다. 통신사에 공인 IP를 요청하거나 임대 서버를
쓰는 수밖에 없습니다.

### 봇 차단

포트를 인터넷에 열어두면 스캐너 봇이 며칠 안에 서버를 찾아냅니다. `봇 차단` 탭에서
`권장 설정 한 번에 켜기`를 누르면 아래가 한꺼번에 적용됩니다.

- 화이트리스트 — 등록한 사람만 접속. 봇을 막는 가장 확실한 수단입니다
- 정품 인증 — 끄면 아무 닉네임으로나 들어올 수 있습니다
- 서버 정보 숨기기 (`enable-status=false`) — 스캐너가 포트를 찾아도 정보를 못 가져갑니다.
  대신 친구들 서버 목록에 인원수가 표시되지 않습니다
- 비표준 포트 — 25565를 피해 눈에 덜 띄는 포트로 옮깁니다
- 접속 보호 — 아래 참고

접속 보호를 켜면 앱이 서버 앞에 앉아 연결을 걸러냅니다. 같은 IP의 동시 접속 수와 1분당
접속 시도 횟수를 제한하고, 한도를 넘긴 IP를 일정 시간 차단하며, 연결만 걸고 아무것도 보내지
않는 연결을 끊습니다. 화이트리스트는 로그인 단계에서 거르기 때문에 그 앞에서 밀려드는
접속 폭탄은 막지 못하는데, 그 구멍을 메우는 기능입니다.

보호를 켜면 서버는 루프백에만 묶여서, 프록시를 거치지 않은 접속은 서버에 닿지 않습니다.
Paper 계열은 PROXY protocol로 실제 접속 IP를 넘겨받아 밴과 접속 기록이 평소대로 동작하고,
모드 서버는 그 기능이 없어 서버에는 접속자가 로컬로 보입니다.

### 그 밖의 탭

- `콘솔` — 서버 명령어 직접 입력 (`op 닉네임` 같은 것)
- `모드 · 플러그인` — jar 파일을 창에 끌어다 놓으면 알맞은 폴더에 들어갑니다.
  서버 종류를 보고 `mods`와 `plugins` 중 맞는 쪽으로 넣어주고, 지우지 않고 잠깐 끄는 것도 됩니다
- `인원 관리` — 관리자, 화이트리스트를 닉네임만 넣어서 추가·제거
- `설정` — 메모리와 서버 설정. 게임 진행, 인원과 거리, 월드, 리소스팩, 성능으로 나뉘어 있고
  맨 아래에서 `server.properties` 원본을 직접 고칠 수도 있습니다
- `백업` — 월드를 통째로 백업하고 사고가 나면 되돌리기. 자동 백업 주기도 설정 가능

## 친구 서버에 참가하기

초대 코드를 받았다면 앱을 켜고 `친구 서버 참가하기`에 붙여넣습니다.
붙여넣는 즉시 어떤 서버이고 무엇이 필요한지 보여주고, `준비하기`를 누르면 아래를 합니다.

- 모드팩을 클라이언트 기준으로 맞춥니다 (서버 전용 모드는 빼고 받습니다)
- 모드 로더를 깝니다
- 공식 마인크래프트 런처에 전용 프로필을 등록합니다
- 게임 안 서버 목록에 그 서버를 미리 넣어둡니다
- 준비가 끝나면 공식 런처를 띄웁니다

방금 만든 프로필이 런처 목록 맨 위에 오므로 플레이만 누르면 됩니다.
게임에 들어가면 서버는 이미 목록에 있습니다.

한 번 준비한 서버는 목록에 남아서 다음부터는 누르기만 하면 됩니다. 팩이 그대로면 다시
받지 않고 넘어가서 몇 초면 끝납니다. 팩이 바뀌었을 때만 달라진 파일을 받습니다.

플러그인 서버(Paper 등)라면 모드를 맞출 필요가 없습니다. 코드에 그렇게 적혀 오고,
참가 쪽도 순정으로 준비합니다.

게임은 이 앱이 켜지 않습니다. 로그인과 실행은 공식 런처가 합니다. 게임 본체와 라이브러리도
런처가 받아둔 것을 그대로 쓰기 때문에, 새로 받는 건 모드팩과 로더뿐입니다.

### 게임 메모리

참가 화면에서 게임에 줄 메모리를 최소(Xms)와 최대(Xmx)로 나눠 정할 수 있습니다.
여기서 정한 값은 다음에 준비하는 서버부터 들어갑니다. 이미 준비한 서버에 적용하려면
그 서버를 한 번 더 준비하면 됩니다.

### 런처를 못 찾을 때

마이크로소프트 스토어나 Xbox 앱으로 설치하면 흔치 않은 자리에 들어가서 못 찾는 경우가
있습니다. 그럴 때는 참가 화면에 런처 실행 파일을 지정하는 칸이 나옵니다. 창에 끌어다
놓거나 직접 찾아주면 다음부터 그 파일을 씁니다.
스토어로 설치했다면 보통 `C:\XboxGames\Minecraft Launcher\Content\Minecraft.exe` 입니다.

### 백신이 다운로드를 막을 때

서명되지 않은 프로그램이 받은 파일을 백신이 검사하면서 내용을 바꿔놓는 경우가 있습니다.
그러면 압축이 안 풀리거나 서버 실행 단계에서 `Hash check failed`가 납니다.
파일 크기는 그대로인데 내용만 달라지기 때문에, 앱은 저장이 끝난 파일을 다시 읽어 해시를
대조해서 이 상황을 잡아냅니다.

두 가지 우회로가 있습니다.

- 자바는 이 PC에 이미 설치된 것을 먼저 찾아 씁니다. 없으면 공식 설치 파일 주소를 안내합니다
- 서버 파일은 `마인크래프트 서버 열기`에서 직접 받아서 넣는 것이 기본값입니다.
  브라우저가 받은 파일은 이 문제가 없습니다

그래도 막히면 설정 탭의 안내에 따라 데이터 폴더를 백신 검사 예외로 등록해 주세요.

## 알아두면 좋은 것

- CurseForge 모드팩은 팩 페이지 Files 탭에서 `Server Pack`을 받아야 합니다.
  클라이언트용 파일에는 모드 파일이 들어있지 않아 서버로 쓸 수 없습니다.
- 자바는 이 PC에 이미 설치된 것을 먼저 찾아 씁니다. 없으면 공식 설치 파일 주소를 안내하고,
  그냥 진행하면 앱이 직접 받아서 씁니다. 정식 설치본을 쓰는 쪽이 백신 문제를 피할 수 있어
  권장합니다. 어느 쪽이든 시스템 자바 설정(JAVA_HOME 등)은 건드리지 않습니다.
- Spigot과 CraftBukkit은 배포 규정상 완성된 파일을 받을 수 없어 이 PC에서 직접 빌드하며
  10~20분 걸립니다. 플러그인 호환은 같으면서 훨씬 빠른 Paper를 권합니다.
- 서버 파일은 `%APPDATA%\TT_ServerMaker\data`에 들어갑니다. 사용자 이름이 한글이면
  모드 호환을 위해 `C:\Users\Public\TT_ServerMaker`로 자동 변경됩니다.

## 개발

```bash
npm install
npm run dev
```

빌드와 배포용 실행 파일 만들기:

```bash
npm run package
```

결과물은 `dist` 폴더에 생깁니다. 설치본(`TT_ServerMaker-0.2.0-x64.exe`)과
설치 없이 쓰는 포터블 실행 파일이 함께 나옵니다.

### 구조

- `src/main` — Electron 메인 프로세스
  - `instance.ts` 서버 생성 흐름 / `pack.ts` 모드팩 임포트 / `loader.ts` 로더 설치
  - `java.ts` 자바 확보 / `server.ts` 서버 프로세스 / `backup.ts` 백업
  - `upnp.ts` 공유기 포트 열기 / `network.ts` 접속 주소 상태 관리 / `guard.ts` 접속 보호 프록시
  - `addons.ts` 모드·플러그인 넣고 빼기 / `players.ts` 관리자·화이트리스트
  - `properties.ts` server.properties 읽고 쓰기
  - `join.ts` 초대 코드로 참가 준비 / `minecraft/` 클라이언트 로더·모드팩·런처 프로필·서버 목록
- `src/preload` — renderer에 노출하는 API
- `src/renderer` — React UI
- `src/shared/types.ts` — 양쪽이 함께 쓰는 타입
- `src/shared/invite.ts` — 초대 코드 (만드는 쪽과 읽는 쪽이 같은 파일을 씁니다)

### 지원하는 서버 종류

플러그인 서버는 Paper, Spigot, CraftBukkit. 모드 서버는 Fabric, Quilt, Forge, NeoForge.
그리고 순정. 모드팩에 적힌 로더 버전을 그대로 쓰고, 지정이 없으면 해당 마인크래프트 버전의
최신 안정 버전을 고릅니다.

## 이 앱이 배포하지 않는 것

이 저장소와 배포본에는 마인크래프트 서버, 자바, 각 로더의 파일이 들어 있지 않습니다.
필요한 파일은 모두 아래 공식 배포처에서 사용자 PC로 직접 받습니다.

- 마인크래프트 서버 — Mojang (piston-meta.mojang.com)
- 자바 — 이미 설치된 것을 우선 사용하고, 없으면 Eclipse Adoptium
- Paper — PaperMC (fill.papermc.io)
- Fabric / Quilt / Forge / NeoForge — 각 공식 배포처
- Spigot / CraftBukkit — 재배포가 금지돼 있어 공식 BuildTools로 사용자 PC에서 직접 빌드합니다
- 모드팩 — Modrinth API, 또는 사용자가 직접 넣은 파일

모드팩이 지정한 파일은 Modrinth가 정한 것과 같은 목록(cdn.modrinth.com, github.com,
raw.githubusercontent.com, gitlab.com)에서만 받습니다. 받은 파일은 모두 해시로 확인합니다.
